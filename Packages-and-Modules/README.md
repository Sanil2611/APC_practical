# 20 Python Modules and Packages — Examples

This ZIP contains 20 small examples showing how to import and use common Python standard-library modules and third-party packages.

## Install third-party packages
Open a terminal and run:
```bash
python -m pip install numpy pandas matplotlib seaborn requests flask pillow scikit-learn
```

Tkinter is included with many standard Python installations. On some Linux systems, it may need to be installed separately. Modules such as `math`, `random`, `datetime`, `statistics`, `os`, `pathlib`, `json`, `csv`, `re`, `collections`, and `sqlite3` are part of Python's standard library.

## Run examples
Extract this ZIP, open the folder in VS Code, and run a file:
```bash
python 01_math_module.py
```
Some examples create files in the current folder. `15_requests_get.py` needs internet access. `14_seaborn_chart.py` may need internet access the first time to load its sample dataset. `16_flask_app.py` starts a local development server; stop it with Ctrl+C. `18_tkinter_gui.py` needs a desktop GUI.

## Note
In Python, a *module* is usually a single importable Python file, while a *package* is a collection of modules. This collection includes examples of both built-in/standard-library modules and third-party packages.
